# Macros tracker

App personal para contar calorías, macros y pasos. Next.js + Supabase + OpenAI, pensada para Vercel.

Variables de entorno (ver `.env.example`): SUPABASE_URL, SUPABASE_SERVICE_KEY, OPENAI_API_KEY, APP_PASSWORD.
La base se crea corriendo `supabase.sql` en el SQL Editor de Supabase.
